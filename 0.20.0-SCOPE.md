# Quick Menu 0.20.0 scope (draft for Tobias, 2026-11-09)

Built from Josh's three 0.19.0 test reports (`TESTING-0.19.0-FINDINGS.md`) and
Tobias's rulings of 2026-11-01, 11-04, 11-07 and 11-09. Numbers are Josh's test
numbers. Items marked **open** still need a word from Tobias; everything else is
ruled and ready to plan.

Lives at the repo root because `docs/` is gitignored here.

Development target: f4 (Foundry 14 + PF1 master) first, so 0.20.0 is forward
compatible, then verified on f1 (Foundry 13 + PF1 11.11), which is where Josh
plays. Both PF1 builds must keep working (see `item.use()` wrapper shapes in the
ops notes).

## A. Command codes

- **1.2** Core skill/save/check codes come from fixed system keys, never from labels, so every character shares them. A leftover alias can never override a core code; old clash aliases are cleared when the core takes over, each move spoken once.
- **1.9 / 1.15** `/fqm reset` restores each item's generated code and speaks every code that moved; no `/scan` advice when nothing needs it. Never remember an alias's code as an item's own.
- **8.40 / 1.1** Rebuild on an item's name change (identification) and speak every code that moves, so nothing moves silently again (Faerie Fire, Technomancy).
- **10.21** Potions, wands and scrolls get spell-style codes: p/w/s prefix plus the spell's four letters or initials (`/pcmw`, `/wclw`, `/sfly`). One announced changeover between games.
- **10.3** Two wands of the same spell stay two commands; players rename to tell them apart. No merging.

## B. What a result says

- **10.16** Item name instead of "Card posted.": name and what happened, then range/duration when the detail level gives them, count last. "Haste on. Range close. 2 of 3 left."
- **10.17** Read every inline roll in a card's effect notes, at every detail level, as the note's words plus its result: "8 images", "Spell penetration 36", Dispel Magic's check, Thunderchonk's duration. Drop "Plus notes". Other notes (situational bonuses, standing defences, hand-applied rules) stay out of the result line. **Open:** how the situational ones reach Josh on demand (a read-notes key or `/notes <code>`).
- **3.6** "see text" range or duration: a linked buff's real duration when there is one, else "see description".
- **6.9** No "threat" or confirm on an always-hit (attack >= 100).
- **8.42** Speak a save DC only when the card's save has a type.
- **8.43** A spell whose heal is temporary hit points says "temporary hit points", not "healing".
- **6.2 / 4.3** Landing on a consumable in the menu speaks its count; the count is spoken before any buff lookup so the first potion of a session is not 4 s late.
- **8.28** A spell that appears in two spellbooks says which: "Detect Magic, spell-like".
- **6.7** `/d` and `/h` results are read (catch PF1's own Damage/Healing cards).
- **10.12** The accept blip plays whenever nothing else confirms a command; every command ends in confirmation or failure.
- **10.26** Any word after an item code that is not `o` / `other` is refused with the error tones and a spoken reason, and nothing is used. (Ruled 2026-11-09.)

## C. Waiting for results

- **8.46** One reader per command, matched to its own card, instead of one shared slot; a skill typed while Scorching Ray is still rolling no longer loses the rays.
- **8.44** A card that arrives late (hidden tab, slow dice) is still read when it arrives; while it waits, say so once ("Lightning Bolt, waiting on the dice."). Look at skipping the Dice So Nice animation when the tab is hidden.
- **6.10** Never cancel a line Chrome has not started, in every path (`noteReset` included).
- **10.2** Gap between lines 150 ms to 100 ms, in code. 50 and 20 follow in later builds after Josh's tests.

## D. Buffs and consumables

- **10.11** One rule: a plain command uses the item on Josh, applies it and speaks it; `/code o` posts the card to chat for someone else and applies nothing. Potions, wands, scrolls, custom items.
- **4.6** Wands and scrolls of a buff spell used on self switch the buff on, found by the spell's name, as potions do now.
- **8.36** Whenever a linked item or spell switches a buff on (Auto Buff), the Quick Menu says so: "Haste on." `/bf` stays the status check. Custom consumables (Greenchaw and friends) are linked on their actions by Tobias/Josh; the Quick Menu assumes nothing about links.
- **10.28** Buff spells follow the same rule. Single-target buffs (Shield, Displacement, Fly): plain = on self, `o` = card only. Multi-target buffs (Haste): plain = buff on for the caster **and every allied token within 15 ft of the caster's token**, if that can be done (ownership permitting, else via the GM socket); `o` = caster not included, card only. (Ruled 2026-11-09.)

## E. The menu and keys

- **2.17** Left at the top level stays put; only Escape closes.
- **8.37** Entering an empty Items category says "<category>, empty." and stays.
- **6.5** Favorites entries are built like their source entries; removing the last favorite works and speaks; Slash on a favorite offers its Slash menu.
- **6.3** A container lists everything inside, read-only with quantities; the chat path handles a container code (`/lds`) instead of "unknown action type: submenu". **Two storage formats:** PF1 11.11 release (f1-f3) keeps contents inside the container item (`system.items`); PF1 master on f4 keeps contents as ordinary actor items with `flags.pf1.container = <bag id>`. Read both.
- **2.19** When joined type-ahead letters match nothing, the newest letter is tried alone.
- **2.18** After Backslash, confirm focus really reached the chat box; otherwise say so and retry.
- **3.8** F9 (any non-printing key) works from the chat box.
- **7.5** Numpad minus/plus work for volume alongside Minus/Equal.
- **2.12** Duplicate-keydown window widened from 10 ms to 15 ms.
- **10.24** Menu numbers dropped (Josh's call), and with them the half-second wait after a digit. Numbers can return as a per-player setting if anyone asks.
- **10.27** Built-in S stop key removed; the chosen stop key is the only one. (Josh's call; ruled 2026-11-09.)
- **2.6** Prepare/unprepare keys exist only for an actor with a prepared spellbook.
